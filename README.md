# 昆虫格闘ゲーム

ファイター5体とアシスト5体から1体ずつ選んで、CPUとBO3で対戦する格闘ゲーム。3段階攻撃・コンボ、体力／必殺／ガード限界／アシストの4ゲージ、1ラウンド3分・タイムオーバー判定つき。ブラウザでそのまま遊べます（`index.html` を開くだけ）。

## ファイター

| ファイター | 必殺・特徴 |
| --- | --- |
| カブトムシ | 吹っ飛ばし |
| クワガタ | 掴みダメージアップ |
| スズメバチ | 3段階攻撃の最後のヒットで毒 |
| カマキリ | 怯み |
| オオエンマハンミョウ | 必殺なし、高速・高攻撃・高防御 |

## アシスト

| アシスト | 効果 |
| --- | --- |
| アリ | ダメージ＋ノックバック |
| 蝶 | 移動反転 |
| ミーデラゴミムシ | 燃焼ダメージ |
| クモ | 拘束 |
| ミツバチ | 回復 |

## 操作

- A / D：移動
- 左クリック：攻撃
- 右クリック：ガード
- Q：掴み
- Space：ジャンプ
- Shift：緊急回避
- E：必殺技
- R：アシスト
- V：ULT

必殺ゲージは攻撃を当てると溜まり、ガードでも溜まる。ガード限界ゲージが満タンになるとスタンする。
